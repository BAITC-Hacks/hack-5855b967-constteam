# Умный подбор подрядчиков (#79-lite)

ИИ-агент помогает заказчику выбрать event-подрядчика из каталога своего города: до трёх карточек и объяснение, почему каждый подрядчик здесь.

## Статус: час 3 — интерфейс

Час 1 — основа подбора:
- загрузка каталога из CSV (`matcher/data.py`) с явным разбором True/False и многозначных полей;
- строгие ограничения: город, категория, тип мероприятия, занятость на дату, цена «от» в бюджете, язык, длительность (`matcher/engine.py`);
- пустое `max_hours` (флорист, декоратор, сувениры) не исключает подрядчика;
- три исхода: подобрали / категории в городе нет / кандидаты есть, но никто не проходит; отдельно — дата вне календаря 23.09–31.12.2026;
- ранжирование по открытым баллам, при равенстве — по id;
- причины отказа по каждому кандидату и альтернативы: ближайшая дата, минимальный бюджет;
- тесты на контрольные сценарии и инварианты (`tests/test_engine.py`).

Час 2 — агент (`matcher/agent.py`):
- код выполняет подбор, агент (LLM с инструментами) получает результат и сам решает, что исследовать;
- инструменты: `try_variant` (другая дата, бюджет, язык, длительность), `compare_dates`, `catalog_overview`, `submit_answer`;
- агент не меняет состав и порядок карточек и условия пользователя;
- ответ проверяется: `id` только из выдачи, 1–2 предложения на карточку, без рекламных фраз, все числа — из данных инструментов;
- не больше 5 шагов и 9 секунд; при сбое, тайм-ауте или отсутствии ключа — резервный режим: объяснения из фактов профиля (`matcher/explain.py`);
- провайдер LLM на выбор: OpenAI или Anthropic (`matcher/llm.py`), один цикл агента для обоих;
- тесты агента на сценарной модели и настоящих SDK OpenAI и Anthropic с поддельными серверами (`tests/test_agent.py`, `tests/test_openai_path.py`, `tests/test_sdk_path.py`).

Час 3 — интерфейс Streamlit (`app.py`):
- форма запроса, до трёх карточек, три исхода различаются цветом и текстом;
- вывод агента и блок «Ход работы агента» со всеми вызовами инструментов;
- «Почему не остальные», альтернативы, сравнение с другой датой;
- режим работы (агент / резервный), время ответа и версия данных внизу страницы.

Доработки агента по прогонам на реальной модели (gpt-4o-mini):
- план по ситуации: какие инструменты доступны и сколько раундов;
- даты в двух форматах, резерв времени на итоговый ответ, лимит параллельных вызовов;
- проверка: верное число подходящих в итоге, ссылка на описание у карточки без отличий, запрет расплывчатых фраз.

## Проверка

```bash
pip install -r requirements.txt
streamlit run app.py                   # интерфейс (Windows: run.bat)
python -m pytest                       # ключ не нужен
python scripts/run_demo.py --no-llm    # контрольные запросы, резервный режим
python scripts/run_demo.py             # с агентом: нужен ключ в .env (см. .env.example)
```
