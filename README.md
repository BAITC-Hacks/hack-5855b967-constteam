# ИИ-агент подбора event-подрядчиков

Заказчик вводит город, дату, тип мероприятия, категорию и бюджет — и получает **до трёх подходящих подрядчиков из каталога** с объяснением, чем каждый отличается, и советом, как выбрать. Если подобрать некого, сервис говорит **почему** и **что можно изменить**.

Кейс HackAlem AI #79-lite «Умный подбор подрядчиков». Это рекомендация, не бронирование.

![Интерфейс: пример «Ведущий на корпоратив»](docs/screenshot.png)

*Пример «Ведущий на корпоратив». Тексты «Как выбрать» и карточек — ответ `gpt-4o-mini` из прогона на этом запросе (3,8 с), каждый прошёл проверку кода.*

## Что решает

| проблема заказчика | что делает сервис |
| --- | --- |
| кто реально подходит? | код проверяет дату, бюджет, формат, язык и часы; занятые на дату не попадают никогда |
| чем они отличаются? | ИИ-агент сравнивает кандидатов и пишет «как выбрать»; каждое утверждение проверяется кодом |
| почему никого нет? | причины отказа по каждому подрядчику; агент сам ищет, какая дата или бюджет дают результат |

## Быстрый старт

Нужен Python 3.10+.

**Windows:** двойной щелчок по `run.bat`.

**Любая ОС:**

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py             # откроется http://localhost:8501
```

**ИИ-агент (необязательно).** Скопируйте `.env.example` в `.env` и впишите ключ OpenAI или Anthropic. Без ключа всё работает, но вместо текстов агента показываются объяснения из фактов профиля — интерфейс пишет об этом внизу.

## Как проверить

Слева в приложении — кнопки **«Примеры»**. Каждая заполняет форму и сразу запускает подбор:

| кнопка | что увидите |
| --- | --- |
| Ведущий на корпоратив | 4 из 10 подходят, показаны 3; совет агента «как выбрать» |
| То же, 11 октября | другой состав; в «Почему не остальные» — «занят 11.10.2026» |
| Редкая: флорист | 1 подрядчик; 8 часов его не исключают — флористу не нужно присутствие |
| Декабрь: все заняты | красный статус «никто не проходит»; ближайшие свободные даты 23.12 и 27.12 |
| Нет категории в городе | жёлтый статус; категория есть в Алматы |

Свой запрос — в форме «Свой запрос» ниже кнопок.

Автоматические проверки (ключ и интернет не нужны; в GitHub они запускаются сами при каждом коммите — вкладка **Actions**):

```bash
python -m pytest                    # 75 тестов: подбор, агент, проверка ответов, сбои API
python scripts/run_demo.py          # те же 5 запросов в консоли, с временем ответа
```

## Технологии

- **Python 3.10+**, **Streamlit** — интерфейс
- **ИИ-агент** на **OpenAI** (`gpt-4o-mini`, `gpt-4.1-mini`) или **Anthropic** (Claude Haiku) через tool use / function calling
- **pytest** + **GitHub Actions** — тесты при каждом коммите; модель в тестах подменяется, ключ не нужен
- Данные — `data/contractors.csv` (66 профилей, копия исходного датасета без изменений)

Без баз данных, векторных хранилищ и обучения моделей.

## Как устроено

```
запрос ─► 1. Код отбирает ─► 2. ИИ-агент анализирует ─► 3. Код проверяет агента ─► экран
           фильтр, 3 исхода,    вызывает инструменты,       числа, id, факты;
           ранжирование         пишет объяснения            не прошло — текст из фактов
```

1. **Код отбирает.** Жёсткие условия по полям каталога, затем баллы за проверяемые признаки, при равенстве — по `id`. Порядок не зависит от модели: тот же запрос — тот же результат.
2. **ИИ-агент анализирует.** Получает результат и сам решает, какие инструменты вызвать: `try_variant` (другая дата, бюджет, язык, часы), `compare_dates`, `catalog_overview`, `submit_answer`. Подходящих достаточно — сразу пишет сравнение; никого нет — ищет, что изменить. Шаги видны в интерфейсе.
3. **Код проверяет агента.** Все числа должны быть из данных, опыт и качество — только со ссылкой на описание, число подходящих — верное, `id` — только из выдачи. Не прошло — объяснение из фактов. Сбой или тайм-аут модели не ломает ответ: карточки показываются сразу.

Подробно: правила фильтра и баллы, план агента, проверки, резервный режим, замеры — в [docs/how-it-works.md](docs/how-it-works.md).
