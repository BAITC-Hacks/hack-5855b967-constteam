# Умный подбор подрядчиков (#79-lite)

Сервис помогает заказчику выбрать event-подрядчика из каталога своего города: до трёх карточек и объяснение, почему каждый подрядчик здесь.

## Статус: час 1 — основа подбора

Готово:
- загрузка каталога из CSV (`matcher/data.py`) с явным разбором True/False и многозначных полей;
- строгие ограничения: город, категория, тип мероприятия, занятость на дату, цена «от» в бюджете, язык, длительность (`matcher/engine.py`);
- пустое `max_hours` (флорист, декоратор, сувениры) не исключает подрядчика;
- три исхода: подобрали / категории в городе нет / кандидаты есть, но никто не проходит; отдельно — дата вне календаря 23.09–31.12.2026;
- ранжирование по открытым баллам, при равенстве — по id;
- причины отказа по каждому кандидату и альтернативы: ближайшая дата, минимальный бюджет;
- тесты на контрольные сценарии и инварианты (`tests/test_engine.py`).

В работе: объяснения через LLM с проверкой ответа и резервным режимом, интерфейс Streamlit.
